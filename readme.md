# About this project
This is a lab project for the student of Advanced Computer
Programming course.

# Requirement
The code require JDK 17 or late.

# How it works
For each lab there will be a branch for it. The main branch the has the empty project with "Hello, world!" message in the "Program.java" class under (edu.uofk.main) package. So there will be 10 branches that will have all the labs.
